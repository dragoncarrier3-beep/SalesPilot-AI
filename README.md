AI-powered Sales Copilot MVP demo for investor and enterprise presentations.

## Features

- Home dashboard (meetings, insights, win probability, pipeline)
- Prospect preparation + AI sales intelligence
- Transcript upload/paste + structured call analysis
- Follow-up generator (email, LinkedIn, CRM notes, recap)
- Live coaching panel simulation
- CRM history with sample companies/contacts
- Manager admin dashboard

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Deploy to Vercel

```bash
npm i -g vercel
vercel
```

Or push this repo to GitHub and import the project in the Vercel dashboard.

No API keys are required for the demo — AI outputs are generated by a deterministic demo intelligence engine with realistic, context-aware responses.
